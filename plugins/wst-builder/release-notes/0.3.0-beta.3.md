# WST Builder Plugin 0.3.0-beta.3

Beta build under test. Adds the same critical ACF clone-source safety hardening as stable `wst-builder` 0.2.1 on top of the in-flight 0.3.0 Section preview harness line.

## Added

- `rules/acf-wst-patterns.mdc`: new hard "ACF Clone-Source Safety" invariants (field-list reads are read-only, `$wpdb` `menu_order`-only reorder, additive-only `acf_update_field` with a fresh key and a numeric `parent`).
- `rules/acf-wst-patterns-reference.md`: new "ACF Field Definition Safety (Clone Sources)" section (safe reorder, safe additive field, snapshot/dry-run/idempotency preflight, clone-integrity scan with a local-store filter). The previous blanket "add fields to DB groups" note is now scoped to the clone-safe path.
- `skills/wst-section-workflow/SKILL.md` and `skills/wst-new-post-type/SKILL.md`: an "ACF structural write gate" before any field-definition write.
- `skills/section-preview-harness/REFERENCE.md`: the field-group-definition note is scoped to the clone-safe path and points at the new reference section.

## Notes

- Builds on 0.3.0-beta.2 (handoff retention) and 0.3.0-beta.1 (Section preview harness); that behavior is unchanged.
- Pairs with `wordpress-server-ops` 0.6.1-beta.2 (generic `programmatic-acf-db-writes` Rule) and stable `wst-builder` 0.2.1.
