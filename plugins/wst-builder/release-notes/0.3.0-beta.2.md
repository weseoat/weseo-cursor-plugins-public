# WST Builder Plugin 0.3.0-beta.2

Beta build under test. Aligns the Section/CPT handoff lifecycle with the new beta retention policy: the handoff is kept until the page goes live (Go-Live) instead of being removed at the end of local frontend QA, so the context is preserved.

## Changed

- `skills/wst-section-workflow/SKILL.md`: the "Handoff lifecycle" cleanup note and the Frontend QA Brief completion line keep the handoff until Go-Live and remove it with `git rm` only afterwards.
- `handoffs/section-handoff.template.md`: the lifecycle intro, the "On completion" note, and the Local Frontend Responsibilities checklist keep the handoff until Go-Live before removal.
- `handoffs/cpt-handoff.template.md`: same handoff-retention wording for the CPT handoff template.

## Notes

- Beta-only change; the stable `wst-builder` plugin and its templates still remove the handoff at the end of local QA.
- Repo-level `section-handoffs/section-handoff.template.md` is updated in lockstep so the `scripts/validate-section-handoffs.py` template drift check keeps matching the beta template.
- Builds on 0.3.0-beta.1 (Section preview harness); that behavior is unchanged.
- Pairs with `frontend-design-qa` 0.4.0-beta.2 and `wordpress-server-ops` 0.6.1-beta.1.
