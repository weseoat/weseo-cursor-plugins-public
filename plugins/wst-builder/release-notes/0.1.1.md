# WST Builder Plugin 0.1.1

Patch release for self-contained WST Builder distribution.

## Added

- Bundled `grill-me` Skill for Section and CPT preflight interviews.
- `plugin-package-boundary` Rule to keep required WST Builder workflows self-contained inside the plugin package.
- Bundled Section handoff template at `handoffs/section-handoff.template.md`.

## Changed

- Section and CPT workflows now explicitly refer to the bundled `grill-me` Skill.
- Section handoff creation now uses the bundled handoff template instead of a repository-local template path.
- Section workflow guidance no longer depends on a repository-local validator script.

## Notes

- Plugin consumers only receive the plugin package, so required workflows must not depend on development-only files outside the plugin folder.
