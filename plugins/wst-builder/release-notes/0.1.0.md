# WST Builder Plugin 0.1.0

Initial tracer release for reusable WST builder guidance.

## Added

- `acf-wst-patterns` Rule for reusable ACF Flexible Content, clone child field, WST shortcode, and Section template invariants.
- Supporting ACF/WST pattern reference material for field structure, clone group expectations, shortcode tables, template shape, and post-meta notes.
- `wst-new-fc-section` Skill for creating a WST Flexible Content Section foundation.
- `wst-new-post-type` Skill for creating a WST Custom Post Type foundation.
- Guidance for WST Section template creation and `flexible-content.php` registration.
- Guidance for creating an ACF section field group with standard content, button, and layout clones.
- Guidance for adding a Flexible Content layout and clone child field with matching `parent_layout`.
- Guidance for CPT setup, optional taxonomy setup, ACF CPT fields, WP Grid Builder grid/card foundation, card templates, and optional single templates.
- Section handoff checkpoint after server-side setup.
- CPT foundation handoff checkpoint before local card/archive/single CSS and QA work.
- Generic example showing the workflow with project-local values supplied by `PROJECT-CONTEXT.md`.

## Notes

- Project-specific ACF keys, field post IDs, CPT names, URL slugs, WPGB IDs, paths, URLs, cache commands, and theme values are read from project context.
- Final CSS refinement, Chrome Local Overrides spikes, responsive QA, and Playwright checks remain part of the local frontend phase.
