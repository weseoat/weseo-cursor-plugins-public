# SmartFlow 1.8.0-beta.2

Prepared 2026-10-13. **Unpublished candidate**, on top of 1.8.0-beta.1. Stable 1.7.0 and the complete experimental cleanup feature remain unchanged. Package counts stay at 24 Rules, 27 Skills and 6 agents.

## Local Skill and Rule submissions

- `smartflow-feedback` can submit a complete locally developed Skill/Rule or a bug's working fix as a reviewed ZIP with its supporting files, source plugin version, project dependencies and actual test evidence. Ordinary feedback remains text-only.
- A bundled standard-library Python helper packs only explicitly selected source files and verifies a schema-versioned manifest, file sizes, per-file hashes and whole-ZIP receipt. It rejects unsafe paths, links, colliding names, unexpected members and oversized input; extraction uses a new scratch directory. It does not scan for every secret or execute contributed scripts.
- Attachment support is discovered from the real MCP schemas before creating the submission. Unique filenames identify revisions; upload is checked by downloading and comparing the exact ZIP hash. A receipt comment names the page, attachment and version. Partial writes are reconciled before a bounded retry.
- Skill/Rule proposals use the live template headings with initial status `eingereicht`; legacy plugin choices are replaced by the actual SmartFlow target/area. Intake does not change existing statuses or hub tables.

## Development-repository companion

The private development clone adds `smartflow-integrate` for area owners: Confluence source review, a human owner decision, one task branch, beta integration, integrated-source retest, and a PR for Anton. Owner-scoped triage/import is documented alongside it. This companion is not bundled in the customer plugin, does not increase the package's Skill count, and is not a runtime requirement for submission.

Owners may accept/reject within their own area; cross-area/shared-policy changes need coordination. Anton retains PR review and publication. A ZIP submission, local test, PR or merge alone does not establish a published fix.

## Validation boundary

Local helper roundtrip/adversarial tests and package/Skill checks are required for this candidate. Live attachment transport, actual colleague permissions, a real customer-project retest and a complete owner PR flow remain open. No Confluence write or publication is implied by this note.
