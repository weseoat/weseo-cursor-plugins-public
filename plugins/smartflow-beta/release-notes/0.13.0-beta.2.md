# SmartFlow 0.13.0-beta.2

`setup-local-project` no longer asks for a master-install name. It reads the current Motherboard hostname from the team's Erstinstallation Confluence page (same locate-the-guide pattern as `weseo-git-installer`) and writes it as `Cloned from`.

## Changed

- `setup-local-project`: the Motherboard hostname is not a user input. After Atlassian MCP is ready, search space `Frontend` for `Erstinstallation` (skip `ALT` backup titles), extract the WESEO Cloner source hostname, and record `Cloned from` plus `erstinstallation_guide`. User-facing German uses "Motherboard", never "Master-Install". If the page cannot be found, ask for the Confluence URL of Erstinstallation, not a free-form name. If MCP is still `pending`, record `Cloned from: pending: Erstinstallation page not readable` and continue.
- `project-css-setup` and `project-template/PROJECT-CONTEXT.md`: `Cloned from` is the Motherboard hostname from Erstinstallation.

## Notes

- Asking testers for a "Master-Install-Name" caused confusion: the team name is Motherboard, and the live identifier already lives on the Erstinstallation page. The hostname is not baked into the plugin — that page is the naming source.
