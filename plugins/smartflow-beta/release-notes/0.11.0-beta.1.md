# SmartFlow 0.11.0-beta.1

The `grill-me` Skill returns: the legacy wst-builder plan interview is back as a standalone SmartFlow Skill, adapted to the work-record model.

## Added

- `grill-me` Skill (adapted from the frozen `wst-builder` plugin): relentless one-question-at-a-time plan interview with a recommended answer per question, explore-first discipline (`PROJECT-CONTEXT.md`, docs layer, codebase, status bridge before asking), and dependency-ordered branch resolution until shared understanding. Output is a written artifact, not a chat summary: a prefilled Section work-record draft (`docs/sections/<slug>.md`) or CPT work-record draft (`docs/post-types/<resource>.md`) with explicit `<unresolved: ...>` placeholders, or a compact decision log for non-WST plans. The legacy handoff drafts are replaced by work-record drafts; the standalone stress-test use ("grill mich") that was lost in the 0.5.0 rework is restored.

## Changed

- `agent-routing` Rule: `grill-me` is added to the "Deliberately Not Routed" list — the Skill runs in the main chat by design, its value is the interactive back-and-forth.

## Notes

- The inline preflights of `wst-section-workflow` and `wst-new-post-type` stay authoritative and unchanged; `grill-me` prefills the work record before a run so the preflight finds recorded decisions instead of open questions.
