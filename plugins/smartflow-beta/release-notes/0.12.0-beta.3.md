# SmartFlow 0.12.0-beta.3

Editorial consistency pass over the agent layer, from the 2026-08-26 agent review (six-agent wiring audit plus external research on current subagent best practices). No workflow semantics change.

## Fixed

- `jira-ticket-runner`: the return format now follows the shared six-field contract from the `agent-routing` Rule (STATUS, EVIDENCE, OWN CHANGES, GATES, OPEN DECISION, NEXT OWNER) plus the ticket-specific `TICKET` line, as `agent-routing` and `jira-batch-workflow` already claimed. The German report material is preserved: `EVIDENCE` carries Ursache and Verifikation in German, `OWN CHANGES` the fix files, `GATES` the Playwright lock release. The STATUS vocabulary is unchanged. The stale "local" phase label was dropped from the description.
- `agent-routing`: the two recommended model slugs that no longer exist in the current model lineup were updated (`gpt-5.6-sol-medium` → `gpt-5.6-sol-high`, `claude-sonnet-5-thinking-medium` → `claude-sonnet-5-thinking-high`); without the fix the two demanding agents (`cpt-figma-analyst`, `wpgb-specialist`) permanently ran in the `inherit` fallback. A maintenance note now states that a permanently missing slug is a signal to update the table, not a runtime problem.
- `wst-new-post-type` 4.5: the leftover "Under package orchestration the `wpgb-specialist` owns this spec" contradicted the always-on routing paragraph (since 0.10.0-beta.1); the specialist owns the WPGB apply-spec on every start.
- `figma-page-builder`: the "Codebase agent deliverable" heading now names the `explore` leaf and states why page composition deliberately uses the generic explorer instead of `cpt-codebase-analyst` (broad, light install inventory vs CPT-package analysis).
- `.cursor-plugin/plugin.json` was stuck at `0.12.0-beta.1` while `manifest.json` carried `0.12.0-beta.2`; both now move together.

## Notes

- Maintainer-repo prose fixed alongside (not shipped): root `README.md` and `WORK_PROGRESS.md` said "five package agents" and "PHP ACF field groups" — now six agents and ACF Local JSON.
- Deliberately unchanged: the agent names (`cpt-visual-implementer` and `cpt-figma-analyst` also handle Sections, but renaming shipped agent identifiers breaks manifest and routing references — a rename would be its own breaking change), the historical release notes, the frozen `Tests/` prototype, and the per-role STATUS vocabularies (intentional design).
