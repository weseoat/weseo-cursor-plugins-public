# SmartFlow 0.1.0

Initial scaffold release of the single successor plugin that replaces the six legacy packages (`wordpress-server-ops`, `wst-builder`, `frontend-design-qa`, and their `-beta` twins).

## Added

- Plugin package skeleton with `rules/`, `skills/`, `agents/`, and `commands/` folders.
- `plugin-package-boundary` Rule for keeping required SmartFlow workflows self-contained inside the plugin package.
- Permanent beta twin `smartflow-beta`, managed with `scripts/manage-beta.py` like the legacy twins.

## Notes

- This is a scaffold: the migrated Rules, Skills, the five Agents, and the Commands land in the wave 1 and wave 2 migrations of the SmartFlow plugin rework plan.
- Hard switch: installing `smartflow` or `smartflow-beta` requires uninstalling all six legacy packages. See `docs/beta-channel.md` for the change stop on the legacy set.
- Project-specific values stay in the project-local `PROJECT-CONTEXT.md` and the project `docs/` layer.
