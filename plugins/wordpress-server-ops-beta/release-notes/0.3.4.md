# WordPress Server Ops Plugin 0.3.4

Adds initial push safety for SmartFlow WordPress-root Git setup.

## Changed

- Requires a restrictive deny-all `.gitignore` before the first `git add`, commit, or push from a WordPress root.
- Allows only repository setup files and approved child theme source paths by default.
- Keeps project-owned plugin paths as an explicit opt-in allowlist.
- Requires `git status --short` verification before the initial commit and push.

## Compatibility

- Existing projects using `wordpress-server-ops` should refresh the WESEO marketplace or plugin cache to pick up the updated setup wizard behavior.
