# WordPress Server Ops Plugin 0.4.2

Fixes a follow-through gap: long setup sessions, terminal interruptions, or chat resets could end without the wizard offering the frontend onboarding handoff at all.

## Changed

- Promotes the previously optional handoff to a mandatory final wizard step `Step 11: Frontend Onboarding Handoff` in `setup-orientation/SKILL.md`. The wizard must display the German handoff prompt verbatim, wait for an explicit answer, record `frontend_onboarding: read | skipped (<reason>) | pending` in `PROJECT-CONTEXT.md`, and may only then claim setup is complete.
- Adds a resume rule to the wizard contract: when invoked after an interruption, the wizard must re-read `PROJECT-CONTEXT.md`, resume from the first missing or pending gate, and finish with Step 11 even if all other gates are already done.
- Adds a `frontend_onboarding` decision to the final verification list, the outputs list, and the completion gates.
- Adds a Frontend Onboarding Handoff walkthrough and updates the wizard flow summary, completion gates, and old-guide coverage mapping in `setup-orientation/reference.md`.

## Compatibility

- Existing projects using `wordpress-server-ops` should refresh the WESEO marketplace or plugin cache to pick up the updated setup wizard behavior. Projects whose `PROJECT-CONTEXT.md` does not yet contain a `frontend_onboarding` field will be prompted on the next wizard run.
