# WordPress Server Ops Plugin 0.6.1-beta.1

Beta build under test. Updates the frontend onboarding handoff guidance so the completion lifecycle matches the new beta retention policy: a finished handoff or mini-handoff is kept until the page goes live (Go-Live) instead of being removed at the end of QA, so the context is preserved.

## Changed

- `skills/setup-orientation/frontend-onboarding.md`: the completion lifecycle, the "never leave uncommitted changes" note, and the visual-only mini-handoff note keep the handoff until Go-Live and remove it with `git rm` only afterwards.

## Notes

- Beta-only change; the stable `wordpress-server-ops` plugin still describes removal at the end of QA.
- Removal at Go-Live stays a manual `git rm` plus commit and push.
- Pairs with `wst-builder` 0.3.0-beta.2 and `frontend-design-qa` 0.4.0-beta.2, which carry the same handoff-retention wording.
