# WordPress Server Ops Plugin 0.3.0

Turns `setup-orientation` into a German guided setup wizard for WESEO Remote-SSH WordPress first setup.

## Changed

- Requires `setup-orientation` to communicate with the user in German while preserving command names, file paths, placeholders, and external UI labels.
- Changes missing setup items from passive blockers into guided wizard branches that ask the user what to do next, execute the chosen path, verify it, and continue.
- Adds German walkthroughs for Remote-SSH setup, Git identity, Bitbucket access token and remote setup, Cursor guidance installation, Project Context filling, WordPress MCP, Figma MCP, and final verification.
- Adds explicit completion gates so the Skill cannot say setup is complete while required setup items are unresolved unless the user consciously skipped them.

## Compatibility

- Secret handling stays unchanged: real tokens, application passwords, SSH keys, token-bearing URLs, `.cursor/mcp.json`, dumps, and scratch files remain local-only and untracked.
- Existing projects using `wordpress-server-ops` should refresh the WESEO marketplace or plugin cache to pick up the updated wizard behavior.
