# WordPress Server Ops Plugin 0.3.3

Improves the SmartFlow Bitbucket Git setup path in `setup-orientation`.

## Changed

- Gives the user a clearer German click-by-click guide for creating a Bitbucket repository access token.
- Requires the agent to open a terminal prompt immediately after the token guide.
- Uses a hidden terminal prompt to read the token locally, set or update `origin`, and run `git fetch origin`.

## Compatibility

- Existing projects using `wordpress-server-ops` should refresh the WESEO marketplace or plugin cache to pick up the updated setup wizard behavior.
