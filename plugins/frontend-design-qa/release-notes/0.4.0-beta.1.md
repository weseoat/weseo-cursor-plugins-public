# Frontend Design QA Plugin 0.4.0-beta.1

Beta build under test. Teaches `frontend-section-qa` to consume the Section preview pages introduced in `wst-builder` 0.3.0-beta.1: when the handoff lists preview URLs, they are the first browser targets, so a single Section is checked in isolation with stable QA hooks before the real page. Distilled from a full Section remodel pilot (2026-06).

## Changed

- `skills/frontend-section-qa/SKILL.md`: the browser QA loop uses preview-page URLs (`/section-preview/<section>/<variant>`) as the first browser targets when the handoff lists them (isolated DOM, fixed fixture data, `#primary[data-preview-section][data-preview-variant]`, `wso-section-preview` and fixture-driven `brand-*` body classes), then verifies on the real page. `n/a (no preview pages)` / `n/a (declined)` means target the real page directly; the local phase never sets up preview pages.
- `skills/frontend-section-qa/SKILL.md`: adds a mandatory cached-page reality check before the final pass (preview pages are nocache and hide stale page cache and Delay-JS bug classes; measure the real page pre-interaction, request a server cache flush if stale).
- `skills/frontend-section-qa/SKILL.md`: server-blocker re-routing is framed as the normal path: at most a clearly-marked interim CSS shim, the blocker recorded with evidence and routed to `wst-section-workflow`, and an honest "pass via interim shim" status until the server fix lands.
- `skills/frontend-section-qa/SKILL.md`: `Inputs` and the workflow checklist now include the `Preview URLs` field and a preview-first browser-target step.

## Notes

- Preview pages are optional project-local infrastructure owned by `wst-builder` `section-preview-harness`. This Skill only consumes the URLs; it never creates or edits preview pages, theme PHP, or server artifacts.
- Final full-page, source-served verification through Playwright MCP stays mandatory. A preview-page pass is never a final pass.
- Pairs with `wst-builder` 0.3.0-beta.1, which offers/sets up the preview pages and writes the preview URLs into the Section handoff.
