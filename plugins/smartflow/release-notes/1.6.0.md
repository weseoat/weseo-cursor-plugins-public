# SmartFlow 1.6.0

Feedback release, promoted from `smartflow-beta` 1.6.0-beta.1 on the same day: thirteen Confluence entries from the 2026-09-25 triage (eleven bugs, two ideas — reported 2026-09-19 to 2026-09-24 on plugin 1.5.0 at Wiener Zucker, Quality Austria, Hotel Hubertus), analysed in `plugin-feedback/` and implemented as five bundles. One new always-on Rule (`runner-gate`, 22 → 23 Rules); the two CSS QA Skills get an Execution Gate; ACF Local JSON gets its pull-before-deploy hook, the `modified` rule, the clone/tab pattern, and the admin-sync hand-over text; the WST Section workflow gets neutral start questions, the same-purpose rule, a foundation-confirmation stop, the mandatory preview-fixtures block, and the per-context four-source proof; the Jira Skills get the Working Tree Discipline, the optional ticket transition, and the mandatory measurement with a one-sentence acceptance criterion; the setup wizards get `--isolated`, the restart-and-verify rule, the browser availability ladder, and the ACF-before-docs gate order. No bridge template change; the bridge stays at 1.1.1.

The full item-by-item description lives in `release-notes/1.6.0-beta.1.md` (Sources, Added, Changed). Each feedback doc's "Umsetzung im Plugin" section names the exact files and text changes for its item.

## Bundles

- **ACF Local JSON** — `acf-local-json` Rule (clone fields and conditional logic, admin-sync hand-over text, JSON conventions checklist, real-UTC `modified`), `setup-acf-local-json` Step 8 with the bundled pre-commit pull hook `assets/pre-commit-acf-json-pull.sh`, `setup-ticket-ready` Gate 1 hook activation. Sources: `acf-clone-conditional-logic.md`, `acf-json-admin-sync-guide.md`, `acf-json-modified-timestamp.md`, `acf-json-pull-before-deploy-hook.md`.
- **WST workflow** — `wst-section-workflow` (three neutral start questions, same-purpose rule, Foundation confirmation block, remodel checklist, Example D, mandatory preview fixtures), `section-preview-harness` (three-state detection, sub-workflow "Configure a further Section"), `wst-shortcodes` (proof per form × nesting context, known runtime constraints), `wst-nested-shortcodes` cross-reference, `wst-shortcode-implementer` (form choice, `OPEN DECISION: preview-offer | preview-fixtures | foundation not confirmed`). Sources: `wst-section-workflow-classification-order.md`, `wst-section-workflow-preview-harness-usage.md`, `wst-shortcodes-deep-loop-runtime-proof.md`.
- **Runner delegation** — new Rule `runner-gate`, Execution Gate in `frontend-section-qa` and `cpt-frontend-qa`, "Inputs you accept" (Resume with current file state) in `cpt-visual-implementer`, non-reasons and prompt split in `agent-routing`. Source: `frontend-section-qa-runner-delegation.md`.
- **Jira** — `deploy-and-branches` Working Tree Discipline, `jira-batch-workflow` baseline and own-changes staging, optional transition on request (Done category via `jira_get_transitions`), `jira-ticket-workflow` mandatory measurement and acceptance sentence, `jira-ticket-runner` return contract (`EVIDENCE` / `OWN CHANGES` / `GATES` / `OPEN DECISION`). Sources: `jira-batch-workflow-foreign-worktree-changes.md`, `jira-ticket-close-on-request.md`, `jira-ticket-workflow-visual-diagnosis.md`.
- **Setup** — `setup-local-project` Step 11 (`--isolated --browser=chromium`, Node 18.17 floor, restart-and-verify after every `mcp.json` change) and Steps 14/15 swapped (ACF Local JSON before the docs layer), `playwright-browser-claim` availability ladder, `auto-docs` `unbekannt` markers for a missing `acf-json/`, `project-template/PROJECT-CONTEXT.md` gate rows. Sources: `playwright-mcp-availability.md`, `setup-acf-json-before-auto-docs.md`.
