# WordPress Server Ops Plugin 0.6.1-beta.2

Beta build under test. Adds the same generic ACF and database write-safety Rule as stable `wordpress-server-ops` 0.6.1 on top of the in-flight 0.6.1-beta.1 frontend-onboarding retention change.

## Added

- New Rule `programmatic-acf-db-writes` at `rules/programmatic-acf-db-writes.mdc` (field-list reads are read-only, no read-then-write-back, additive-only `acf_update_field` with a fresh key and a numeric `parent`, `$wpdb` `menu_order`-only reorder, mandatory snapshot/dry-run/idempotency/rollback/verify). WST/ACFE clone specifics route to `wst-builder` `acf-wst-patterns`.

## Changed

- Manifest, plugin descriptor, README "Included Content", and release-notes pointer reflect the new Rule and the bumped version.

## Notes

- Builds on 0.6.1-beta.1 (frontend-onboarding handoff retention); that change is unchanged.
- Pairs with `wst-builder` 0.3.0-beta.3 and stable `wordpress-server-ops` 0.6.1.
