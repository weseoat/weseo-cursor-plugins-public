# WordPress Server Ops Plugin 0.3.5

Clarifies Bitbucket repository access token creation in `setup-orientation`.

## Changed

- Adds explicit Bitbucket navigation for creating a repository access token.
- Specifies where to find `Permissions` / `Repository permissions` in the token dialog.
- Tells the user to enable repository `Read` and `Write` permissions and avoid admin permissions.

## Compatibility

- Existing projects using `wordpress-server-ops` should refresh the WESEO marketplace or plugin cache to pick up the updated setup wizard behavior.
