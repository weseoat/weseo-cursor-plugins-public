# WordPress Server Ops Plugin 0.4.1

Fixes a usability gap in the `setup-orientation` Bitbucket step: the wizard could open a token prompt before explaining where the token comes from.

## Changed

- Step 4 in `setup-orientation/SKILL.md` now requires the wizard to display the full German Bitbucket Access Token creation guide in chat and wait for explicit user confirmation before opening any terminal or asking for the token.
- The Bitbucket walkthrough in `setup-orientation/reference.md` enforces the same strict order: confirm repo, show creation guide, only then open the integrated terminal and run the hidden token prompt.
- Inlines the German token creation message directly in `SKILL.md` so it cannot be skipped through progressive disclosure.

## Compatibility

- Existing projects using `wordpress-server-ops` should refresh the WESEO marketplace or plugin cache to pick up the updated setup wizard behavior.
