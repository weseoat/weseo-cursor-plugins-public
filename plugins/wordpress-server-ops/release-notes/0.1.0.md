# WordPress Server Ops Plugin 0.1.0

Initial tracer release for reusable WordPress server operations guidance.

## Added

- `server-phase-boundary` Rule for separating Remote-SSH WordPress work from local frontend implementation.
- `webroot-safety` Rule for keeping scratch and export artifacts out of public WordPress roots.
- `file-edit-boundary` Rule for respecting project-approved editable paths.
- `wp-cli-cache` Rule for using project-local WP-CLI and cache commands.
- `wordpress-content-editing` Rule for safe REST and ACF Flexible Content updates.
- `setup-orientation` Skill for Cursor Remote-SSH orientation, WordPress root setup, local Git access, Project Context placeholders, local-only MCP config, and setup scratch policy.
- `wp-media-import` Skill for generalized media import, metadata, verification, cache flushing, and cleanup.

## Notes

- Project-specific paths, URLs, upload policies, command aliases, path exceptions, repository access methods, and setup coordinates are read from the project template.
- Real tokens, application passwords, SSH keys, database dumps, and `.cursor/mcp.json` stay local-only and untracked.
- Section changes should update a Section handoff before local CSS or Playwright work begins.
