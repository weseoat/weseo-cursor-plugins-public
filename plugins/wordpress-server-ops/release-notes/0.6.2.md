# WordPress Server Ops Plugin 0.6.2

Updates the frontend onboarding handoff guidance so the completion lifecycle matches the handoff retention policy shipped with `wst-builder` 0.3.0 and `frontend-design-qa` 0.4.0: a finished handoff or mini-handoff is kept until the page goes live (Go-Live) instead of being removed at the end of QA, so the context is preserved. Promoted from `0.6.1-beta.2`.

## Changed

- `skills/setup-orientation/frontend-onboarding.md`: the completion lifecycle, the "never leave uncommitted changes" note, and the visual-only mini-handoff note keep the handoff until Go-Live and remove it with `git rm` only afterwards.

## Notes

- Removal at Go-Live stays a manual `git rm` plus commit and push.
- Includes the `programmatic-acf-db-writes` Rule from `0.6.1` unchanged.
- Pairs with `wst-builder` 0.3.0 and `frontend-design-qa` 0.4.0, which carry the same handoff-retention wording in the handoff templates, the WST Section workflow, and the QA skills.
