# WordPress Server Ops Plugin 0.2.0

Improves `setup-orientation` from passive orientation into a complete WESEO Remote-SSH first-setup workflow.

## Changed

- Expanded `setup-orientation` to actively detect the WordPress root, Git repository, branch, redacted remote identity, WP-CLI command, cache command, Cursor Rules/Skills, and safe temp path.
- Added guidance for creating or updating `PROJECT-CONTEXT.md` with detected non-secret setup facts.
- Added WESEO SSH defaults for `astra-child`, WST plugin paths, local `wp-cli.phar`, cache flushing, Bitbucket token remote redaction, and local-only `.cursor/` guidance.
- Added stop conditions for ambiguous roots, new Git repositories, remote replacement, credentials, live-site-affecting commands, and potentially public temp paths.
- Updated the setup reference with discovery commands, Project Context auto-fill rules, verification checks, and open-question formatting.

## Compatibility

- Existing project-specific secrets, token-bearing remotes, `.cursor/mcp.json`, dumps, and scratch files remain local-only and untracked.
- Projects using marketplace-installed plugins should refresh the WESEO marketplace after the public distribution repository is synced.
