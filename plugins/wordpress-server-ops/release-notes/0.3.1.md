# WordPress Server Ops Plugin 0.3.1

Tightens the `setup-orientation` Git setup path for SmartFlow first setup.

## Changed

- Treats a missing Git repository in a verified WordPress root as the prescribed SmartFlow Bitbucket setup path instead of a multiple-choice branch.
- Guides the user through creating a Bitbucket repository access token with `Read` and `Write` permissions.
- Keeps real tokens out of chat, tracked docs, screenshots, commits, and `PROJECT-CONTEXT.md`; token entry remains local-only through terminal input or local Git commands.
- Updates the reference prompts and completion gates so Git is not treated as a normal optional skip for SmartFlow projects.

## Compatibility

- Existing projects using `wordpress-server-ops` should refresh the WESEO marketplace or plugin cache to pick up the updated setup wizard behavior.
