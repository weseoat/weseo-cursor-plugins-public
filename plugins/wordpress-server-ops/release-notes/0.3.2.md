# WordPress Server Ops Plugin 0.3.2

Publishes the SmartFlow setup-orientation Git flow with public-distribution-safe token placeholders.

## Changed

- Keeps the prescribed Bitbucket setup flow from `0.3.1`.
- Uses only the approved `https://x-token-auth:<token>@<repo-host>/<repo-name>.git` placeholder shape in release artifacts.

## Compatibility

- Existing projects using `wordpress-server-ops` should refresh the WESEO marketplace or plugin cache to pick up the updated setup wizard behavior.
