# WordPress Server Ops Plugin 0.6.0

Adopts the `commit-trailer` Rule from the retired `smartflow-tracer` tracer plugin so the `Made with: SmartFlow` commit convention now ships with a maintained, distributed plugin instead of an internal example package.

## Added

- New Rule `commit-trailer` at `plugins/wordpress-server-ops/rules/commit-trailer.mdc`. Keeps the SmartFlow commit trailer convention: prefer `--trailer "Made with: SmartFlow"` and replace any `Made-with: Cursor` trailer inserted by local tooling. The Rule stays free of repository-specific hook paths, access details, and server assumptions.

## Changed

- `wordpress-server-ops` manifest, plugin descriptor, README, and release-notes pointer reflect the new Rule and the bumped version.
- The `smartflow-tracer` tracer plugin is retired; its only content (`commit-trailer`) now lives here.

## Compatibility

- Existing setup gates, safety boundaries, and Skills are unchanged.
- The Rule is bundled inside the plugin package and does not depend on `weseo-smartflow-frontend-guide`, `.agents`, `.scratch`, `.cursor/plugins/cache`, or any other development-only path.
