# WordPress Server Ops Plugin 0.4.3

Polishes the user-facing setup documentation around `setup-orientation` so the package docs match the wizard's plain-language behavior.

## Changed

- Updates `setup-orientation/frontend-onboarding.md` to explain the three WESEO plugins, Remote/server vs. local frontend work, `PROJECT-CONTEXT.md`, Figma usage, handoffs, and safety rules in everyday German while preserving exact plugin names, file names, command names, and UI labels.
- Updates the WordPress Server Ops README to describe `setup-orientation` as a guided German wizard that leads with plain-language explanations and concrete user actions before technical details.
- Documents that the final setup summary should start with a non-technical overview, followed by technical completion details and any remaining `pending` next actions.
- Reinforces credential wording: real access values must not be placed in chat, `PROJECT-CONTEXT.md`, Git, commits, tracked files, diagnostics, screenshots, or public webroot artifacts.

## Compatibility

- Existing setup gates and safety boundaries are unchanged. This release only changes reusable guidance and documentation wording.
